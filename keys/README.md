# 可信公钥

此目录只允许保存经维护者独立核对的 **公开** Ed25519 公钥及说明。当前未提供生产公钥，因此本初始化包不包含任何公钥文件，不包含测试密钥，也不宣称 App 已信任本仓库。

App 的信任根必须来自应用内预先配置的公钥，不能从下载到的清单中接收新公钥后立即信任。GitHub 仓库、HTTPS 或文件名本身不提供签名信任。

启用前由维护者在受控环境准备 Ed25519 密钥，核对公开密钥来源、`keyId` 与指纹。生产私钥必须位于 **任何 Git 仓库之外**，不得进入源码、APK、提交、附件、Issue、CI 日志或本目录；不要发送私钥给协作者或自动化代理。`.gitignore` 不能代替私钥管理。

发布工具的 `--public-key` 文件内容为 **32 字节原始 Ed25519 公钥的标准 base64**，不能直接把带头尾的 PEM/SPKI 文本或 DER 文件当作原始公钥。确认后可在此保存公开 base64 文件，并记录公开的 `keyId`、SHA-256 指纹、独立确认方式和启用的 App 版本。不要记录私钥路径或私钥信息。

本仓库公开密钥文件只供核对；App 是否信任仍由随 App 发布的 `RestrictionSyncConfig.trustedPublicKeys` 决定。换钥必须先规划旧 App 与持久化信封历史的兼容，再经审核发布，不能通过直接替换公钥让旧签名历史失去验证能力。

签名与验证流程见 `../docs/publishing.md`。本阶段不生成生产密钥，也不设置生产公钥。
